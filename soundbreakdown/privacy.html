隐私政策

英语发音拆解（macOS）· 更新于 2026-11-18

一句话：这个 App 没有账号、没有统计 SDK、不上传你的任何内容。所有学习记录都只存在你自己的电脑上。

我们不收集什么

  • 不收集姓名、邮箱、电话、位置、设备标识符等任何个人信息
  • 不集成任何第三方分析、广告或崩溃上报 SDK
  • 不需要注册或登录

会联网的两种情况（都由你主动触发）

  • 下载真人语音包：从本项目的对象存储地址下载约 20 MB 的音频压缩包。请求只包含文件地址，不包含任何个人信息。下载完成后，朗读完全离线。
  • 可选的云端语音（默认关闭）：如果你在设置里填入自己的 Fish Audio API Key 并开启，朗读时会把当前句子的文本、语速和音色参数发送到 api.fish.audio 合成音频。该服务由第三方提供，受其隐私政策约束。不填 Key 时不会发出任何请求。

本地存储

以下内容保存在本机（~/Library/Application Support 与 UserDefaults），不会上传：

  • 界面偏好：主题色、字号、窗口位置与大小、口音、滚动间隔等
  • 已下载的语音包音频
  • 你选择的克隆参考音频路径（仅存安全作用域书签，音频本身不复制、不上传，除非你开启云端克隆）

剪贴板

只有在你点击「从剪贴板拆解」时，App 才读取剪贴板中的文本，用于生成练习卡片；不会保存或上传。

儿童

App 不面向儿童收集任何信息，也没有任何账号或社交功能。

你的控制权

  • 删除 App 即删除全部本地数据
  • 删除语音包：访达前往 ~/Library/Application Support/SoundBreakdown/VoicePack
  • 随时在设置里关闭云端语音
